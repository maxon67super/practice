# Работа №8. Тестирование

Структура `Kinematics` для кинематических расчётов (вариант 6) и модульные тесты.

- `Kinematics.h` — структура со статическими методами velocity, distance, time, acceleration;
- `main.cpp` — демонстрационная программа;
- `tests_runner.cpp` — запуск тест-кейсов: 2 позитивных, 2 негативных и тест функции напарника.

Сборка: `g++ -std=c++17 -o tests tests_runner.cpp`
